# SupportDesk AI

Fullstack helpdesk application with AI-powered ticket management.

## Tech Stack

**Frontend:** React + TypeScript + Vite + TailwindCSS  
**Backend:** Node.js + Express + TypeScript  
**Database:** PostgreSQL (Neon) + Drizzle ORM  
**AI:** Anthropic Claude API  
**Testing:** Vitest + Playwright  

## UI Reference
Design inspired by "Ticket Support System" (Figma Community)

## Getting Started

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev
